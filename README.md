# Sori: Learn Korean by Sound

한국어 듣기·표현 학습과 친구 초대형 한국 여행 가이드를 연결하는 웹 앱입니다. 학습 화면은 정적 파일이며, 여행 공동 편집은 별도 API와 영구 저장소를 사용합니다.

## 개발 시작

Node.js 24 이상을 설치한 환경에서 저장소 폴더를 엽니다. 검사 의존성은 npm ci로 설치합니다. 기본 로컬 협업 API는 격리된 SQLite에 저장되며, 운영에서는 별도 Worker API와 비공개 R2 문서 저장소를 사용합니다.

```sh
npm ci
npm test
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 종료는 Ctrl+C, 다른 포트는 환경변수 PORT로 지정합니다. 서버는 로컬 컴퓨터에서만 접속하도록 설정되어 있으며 서비스용 배포 서버가 아닙니다.

## 여행 가이드 V1

홈에서 Seoul guide를 선택하면 서울 1–3일 일정을 만들고 친구를 초대해 함께 장소와 메모를 수정할 수 있습니다. 한국어 학습은 별도 핵심 메뉴로 유지하며 가이드의 표현에서 실제 학습 카드로 연결됩니다. [V1 기능·운영 연결 범위](docs/guide-v1.md)를 참고하세요.

## 파일 구조

- `index.html`: 화면, 스타일 일부, 인증·음성 관련 인라인 코드
- `data/`: 5개 표현 카테고리, 정규화, 명사·말투 설명
- `js/`: 앱·퀴즈·인증·저장·음성
- `css/`: 퀴즈·사이드바·공지 스타일
- `scripts/`: 개발 서버와 오프라인 기본 검사

## 검사 범위

`npm test`는 HTML에 연결된 JavaScript의 문법, 로컬 스크립트·스타일 존재, 표현 데이터의 필수 값과 정규화 ID 중복, manifest JSON, 개발 서버의 응답·접근 제한을 확인합니다. 실제 브라우저 클릭·소리 품질·로그인·클라우드 저장·모바일 표시 검사는 별도입니다.

## 외부 서비스와 다음 확인 사항

현재 프런트엔드는 Firebase 프로젝트 `sori-533fc`, 별도 프로젝트의 TTS 함수, Google Analytics와 외부 CDN을 참조합니다. 로컬 실행도 이 주소를 사용하므로 오프라인 검사와 실제 브라우저 실행의 영향을 구분해야 합니다. 이 저장소에는 Cloud Functions 소스, Firestore 규칙, Firebase Hosting 설정이나 에뮬레이터 설정이 없습니다. 관련 백엔드를 이 저장소만으로 복구·배포할 수 있다고 가정하지 않습니다.

이번 개발 브랜치에서 정리한 항목:

- 로그인 버튼의 중복 처리 제거, popup 차단 시 redirect 전환, 로그인 실패 안내.
- Auth와 Firestore를 같은 modular SDK로 연결. 사용자별 기기 캐시와 재시도 가능한 즐겨찾기 변경 기록 분리.
- 음성 재생을 공통 Cloud Functions 플레이어로 통일. 이전 요청 취소, 응답·오디오 오류·시간 초과 처리, 실제 재생 종료 후 반복 횟수 증가.
- 선택적으로 적용할 Supabase 저장 어댑터와 SQL 초안. 기본값은 Firestore이며 실제 전환·데이터 이전은 수행하지 않음.

브라우저에서 클라우드 음성 재생 종료 후 횟수 증가와 모바일 폭을 확인했습니다. 실제 Google 로그인과 기존 계정 데이터의 별도 검증 범위는 유지합니다. Supabase 전환 조건과 기존 기기 캐시 보존 정책은 [저장소 전환 문서](docs/storage-transition.md)를 참고하세요. 과거 계정 정보가 없는 기기 캐시는 별도 백업만 남기고 다음 로그인 사용자에게 자동으로 합치지 않습니다.

## 운영 여행 저장소

Supabase 전용 프로젝트 생성은 무료 프로젝트 한도로 거절되어 기존 회사 DB는 변경하지 않았습니다. 여행 API는 별도 Sites Worker와 비공개 R2 저장소로 구성했습니다. 일정 전체를 ETag 조건부 쓰기로 저장해 동시 수정·초대 수락을 원자적으로 처리합니다. 클라이언트는 js/config.js의 공개 API 주소만 사용하며, 개인 일정 접근에는 개별 멤버십 토큰이 필요합니다.

`hosting/trips-api`는 배포한 서버 소스와 manifest, 재현 가능한 빌드 스크립트를 보존합니다. `supabase/trip-storage.sql`과 Edge Function 소스는 향후 PostgreSQL 이전을 위한 검증된 후보이며 운영 Supabase를 생성했다는 의미가 아닙니다. [운영 배포 문서](docs/production-release.md)를 참고하세요.
